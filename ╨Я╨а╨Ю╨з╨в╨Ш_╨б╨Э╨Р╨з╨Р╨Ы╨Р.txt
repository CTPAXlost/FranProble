FRANPROBE 2.0 — КАК ПОЛУЧИТЬ APK ЧЕРЕЗ GITHUB

1. Распакуйте архив проекта.
2. Создайте на GitHub новый пустой репозиторий.
3. Загрузите ВЕСЬ СОДЕРЖИМЫЙ каталог проекта в корень репозитория.
   В корне GitHub должны лежать settings.gradle.kts, build.gradle.kts,
   папки app и .github.
4. Откройте вкладку Actions.
5. Выберите workflow «FranProbe Android build» и запустите Run workflow.
6. После зелёной галочки откройте запуск и скачайте артефакт
   FranProbe-debug-APK.
7. Внутри артефакта будет FranProbe-2.0.1-debug.apk.

Workflow не скрывает ошибки: сначала выполняются unit-тесты и Android Lint,
затем собирается APK. Отчёты сборки сохраняются отдельным артефактом.

ПРИ ПЕРВОМ ЗАПУСКЕ FRANPROBE

• Для проверки сети оператора отключите VPN.
• Запустите сначала «Полную» диагностику.
• Во время белых списков сохраните ZIP-отчёт кнопкой с дискетой.
• Для сравнения сделайте второй отчёт в обычном режиме сети.
• В режиме «Матрица SNI» укажите прямой IP и порт сервера.
  Если базовый TCP не проходит, программа не будет выдавать результаты SNI
  за доказательство обхода.

СОХРАНЕНИЕ ЛОГОВ

Каждый завершённый запуск автоматически хранится в приложении.
Сохраняемый ZIP содержит:
• TXT — понятный отчёт;
• JSON — полные структурированные данные;
• CSV — таблицу;
• RAW.LOG — одна техническая строка на тест;
• README — пояснение статусов.
