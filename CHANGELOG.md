# История изменений

## 2.0.4 — 2026-08-03

- Полностью разобран свежий GitHub Actions-лог: единственной корневой ошибкой была собственная задача `verifyApi36Dependencies`, а Android-компиляция ещё не запускалась.
- Ошибочная ручная задача удалена вместе с неиспользуемыми `lifecycle-runtime-ktx` и `lifecycle-viewmodel-compose`.
- GitHub Actions теперь выполняет 15 обязательных этапов за один проход: структура, clean, зависимости, три dependency insight, AAR metadata, manifest, ресурсы, основной Kotlin, Kotlin unit-тестов, unit-тесты, lint и APK.
- Каждый этап сохраняет отдельные `.log` и `.exit-code`; общий провал выдаётся только после попытки выполнить весь набор.
- Исправлено сохранение bootstrap-логов: агрегатор больше не удаляет логи создания Gradle Wrapper и установки Android SDK.
- Добавлены `activity-ktx` и фиксированные совместимые версии зависимостей под API 36; удалена хрупкая проверка наличия отдельных runtime-JAR.
- Системное DNS переведено на прерываемый вызов, чтобы coroutine timeout не зависал на блокирующем `getAllByName`.
- Неподдерживаемая устройством версия TLS теперь получает `NOT_TESTED`, а не ложную сетевую ошибку.
- Проверка ALPN HTTP/2 различает `h2`, fallback на `http/1.1`, отсутствие ALPN и невозможность теста на Android ниже API 29.
- Обрезанный DNS-ответ всегда получает `LIMITED` и повторяется по TCP; он больше не может считаться полным успешным ответом.
- DNS-парсер теперь проверяет класс исходного вопроса и границы RDATA до чтения данных.
- Добавлены unit-тесты несовпадающего DNS-класса и завышенной длины RDATA; всего в проекте 13 unit-тестов.
- DoT использует системное хранилище доверия Android и hostname verification; DoH подключается к заданному IP без системного прокси.
- TLS-рукопожатие и последующая HTTP-ошибка фиксируются отдельно; ICMP/UDP Port Unreachable также выделен отдельно.
- Временные ZIP экспорта удаляются после сохранения или отмены; история отчётов исключена из backup/device transfer.
- User-Agent всегда берётся из `BuildConfig.VERSION_NAME`.
- Версия приложения и имя APK обновлены до 2.0.4.

## 2.0.3 — 2026-08-03

- Compose переведён с BOM 2026.06.00 на стабильный BOM 2025.08.00 (Compose 1.9).
- Activity Compose зафиксирован на 1.11.0, Lifecycle — на 2.9.4.
- В GitHub Actions добавлен `dependencyInsight` и явный запрет разрешения Core 1.18/1.19.
- Версия приложения и имя APK обновлены до 2.0.3.

## 2.0.2 — 2026-08-03

## 2.0.1 — 2026-08-03

- Исправлена остановка GitHub Actions на проверке `gradle-wrapper.jar`.
- Неверная контрольная сумма заменена официальной SHA-256 для Wrapper Gradle 9.5.0.
- SHA-256 дистрибутива Gradle теперь передаётся прямо задаче `wrapper` и проверяется в properties.
- Добавлена проверка дерева исходников до запуска Gradle.
- `actions/upload-artifact` обновлён до Node.js 24-совместимой версии v7.
- Сборка APK запускается с `--no-daemon`; отсутствие APK теперь считается ошибкой.

## 2.0.0 — 2026-08-03

Полное пересоздание FranProbe с нуля.

- Послойная диагностика: сеть → DNS → IP → TCP/UDP → TLS/SNI → HTTP.
- `NOT_TESTED` вместо ложного `BLOCKED`, если зависимый тест не запускался.
- Системный DNS и прямые DNS-запросы UDP/TCP с проверкой transaction ID и вопроса.
- A/AAAA, CNAME, RCODE, TTL и повтор DNS по TCP при truncation.
- DoT и настоящий DoH с HTTP/2/HTTP/1.1 и штатной проверкой сертификата.
- Продолжение тестов по IP, полученному независимым резолвером.
- Отдельные IPv4/IPv6 TCP-проверки.
- Матрица SNI: без SNI, пользовательские SNI, TLS 1.2/1.3, ALPN и Host без SNI.
- Subject/SAN сертификата и ручная проверка соответствия SNI.
- UDP без ответа получает `INCONCLUSIVE`, а не ложную блокировку.
- История последних 20 запусков.
- Экспорт ZIP: TXT, JSON, CSV, RAW.LOG и README.
- GitHub Actions: unit-тесты, lint и сборка APK без `continue-on-error`.
